# ChatGPT Image Prompts — Kiosk Apparel Lifestyle

Paste each prompt into **ChatGPT → Create image**. Attach the listed reference logos when noted.

**Reference files (attach from repo `images/`):**
- `KiosK.jpg` — white monogram + wordmark on black (primary brand DNA)
- `KiosK-BOX-Logo-NO-BG.jpg` — black monogram + wordmark on transparent/light
- `Wht-Logo.png` — geometric wordmark style reference

**Global rules (prepend mentally to every prompt):**  
Photoreal ecommerce lifestyle photo. Natural or soft ambient light. Shallow depth of field. Garment is the hero; print on chest must be sharp and legible. No watermarks, no UI overlays, no floating badges, no collage. Adult model, diverse casting OK. 3:4 portrait framing preferred.

---

## How to use

1. Attach logo refs listed for that print.
2. Paste the prompt.
3. Save export as `{id}-{colorway}-{street|airport}-01.png` into `images/product-lifestyle/_staging/`.
4. Agent converts to WebP into `tees/` or `hoodies/`.

## Regeneration tips

- If print warps: “keep chest graphic flat, undistorted, screen-print accurate to reference logo.”
- If logo wrong: re-attach `KiosK.jpg` and say “match this exact monogram geometry.”
- If too busy: “simplify background, garment fills most of frame.”
- If AI invents neon colors: “restrained neutrals only; no neon, no purple glow.”
