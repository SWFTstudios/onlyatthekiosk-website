# On-model lifestyle prompts

These are prompts for photographs of people wearing the quote pieces. Generate them with the repo's OpenAI pipeline (`scripts/generate-product-images.js`, which needs `OPENAI_API_KEY`) or any image tool. For the most accurate print, attach the matching back render from `images/shop/3d/` as a reference image. Check every result: image models can misspell the quote.
